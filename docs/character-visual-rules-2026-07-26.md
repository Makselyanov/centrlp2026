# Визуальные правила персонажа CentrLP

Этот файл относится к публичным иллюстрациям с мультяшным персонажем Макса.
Текст промптов и рабочие заметки не должны попадать в публичные страницы.

## Каноническая идентичность

- Канонический персонаж: `max-cartoon-ink-v1`.
- Источник: `G:\mvp\HUB\video-factory\packs\centrlp\canonical-packs.json`.
- Неизменяемые признаки: короткая прямая тёмная чёлка, тёмные брови, карие глаза,
  чисто выбритое овальное лицо, пропорции лица и тела.
- Можно менять одежду, позу, реквизит, место действия и ракурс.
- Нельзя добавлять бороду, очки, другое лицо, фотоподобную замену лица или пластиковый 3D-стиль.

## Обязательные правила для новых изображений

1. Каждая сюжетная иллюстрация создаётся отдельным промптом.
2. Изображение должно показывать конкретное действие, которое понятно без подписи.
3. Настоящие заголовки, цены, кнопки и пояснения выводятся HTML-текстом рядом с изображением.
4. Запрещены псевдотекст, нечитаемые строки, фейковые интерфейсы, абстрактные дашборды,
   плавающие карточки, голограммы, неоновые нейросети и декоративные «технологичные» схемы.
5. Запрещено заменять смысл страницы роботом, мозгом, графиком или набором экранов без реального сюжета.
6. Перед подключением к странице изображение проверяется в полном размере, после WebP-сжатия
   и внутри desktop/mobile-макета.

## Финальный набор промптов

### `public/images/prices/max-pricing-guide-v1.webp`

- Задача: персонаж показывает реальные ценовые ориентиры, которые выводятся HTML-блоками слева.
- Сцена: светлый бумажный фон, Макс справа, открытая ладонь направлена в свободное пространство.
- Одежда: синяя рабочая куртка, чёрная футболка, тёмные брюки, светлые кеды.
- Реквизит: чистый планшет-папка без надписей.
- Запреты: текст, цифры, валютные символы, монеты, весы, экраны, карточки интерфейса, робот, неон.

### `public/images/ai/max-ai-workflow-v1.webp`

- Задача: показать маршрут `обращение → карточка клиента → задача → подтверждение`.
- Сцена: реальный светлый рабочий стол; телефон, папка, физическая карточка и штамп
  связаны одной синей лентой.
- Одежда: тёмно-бирюзовая рабочая рубашка поверх белой футболки.
- Запреты: псевдотекст, дашборды, код, голограммы, роботы, киберпанк и светящиеся нейросети.
- Правка после первой генерации: серые псевдостроки на карточке удалены,
  оставлены только цветные маркеры и пустые квадраты.

### `public/images/ai/max-ai-control-v1.webp`

- Задача: показать правило «AI готовит, человек проверяет и разрешает».
- Сцена: Макс ставит зелёный штамп на чистый документ, держит три ключа доступа,
  рядом закрытый ящик с замком.
- Одежда: светло-серая рубашка поверх тёмно-бирюзовой футболки.
- Запреты: текст, имитация документов, интерфейсы, роботы, голограммы и дополнительные персонажи.
- Правка после первой генерации: все псевдостроки на документах удалены.
