# Photorealistic service visual prompts, rest batch, 2026-06-30

Internal production prompt pack for the second CentrLP service visual batch.
These prompts are not public page copy.

## Shared Anti-Slop Direction

1. Use real photographed product scenes.
2. Show real devices on a real desk.
3. Make the interface purpose visible.
4. Prefer laptop plus phone when the service has both manager and client sides.
5. Show the path from request to action.
6. Show CRM, status, source, log, or next step where relevant.
7. Use short Russian UI labels only.
8. Avoid big blocks of generated text.
9. Avoid personal data.
10. Avoid real phone numbers.
11. Avoid Moscow geography unless the page explicitly needs it.
12. Prefer Tyumen or neutral local-business context.
13. No floating icons.
14. No holograms.
15. No glowing brains.
16. No humanoid robots.
17. No plastic 3D icons.
18. No pastel isometric scenes.
19. No giant brand-logo posters.
20. No copied proprietary dashboards.
21. Use natural daylight or soft office light.
22. Use realistic glass reflections.
23. Use realistic shadows.
24. Include tactile props: paper, pen, notebook, cable, cup.
25. Keep important devices safe inside a 1200x630 crop.
26. The image must work as a service page band.
27. The image must work as an OpenGraph preview.
28. The result should feel like a real CentrLP case-study photo.
29. The product should feel launch-ready.
30. The scene should sell clarity, control, and business value.
