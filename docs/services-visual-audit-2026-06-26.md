# Аудит изображений CentrLP от 2026-06-26

Цель: убрать с публичных страниц изображения, которые выглядят как бессмысленный AI-рендер или как текстовый слайд внутри страницы.

Новое правило: видимое изображение в теле страницы должно разбавлять текст и помогать понять смысл без дополнительного чтения. Внутри таких изображений не должно быть заголовков, списков, рекламных формулировок, псевдотекста и фейковых логотипов. Допустимы только реальные логотипы платформ там, где они являются визуальным знаком канала.

## Что сделано

| Зона | Статус |
|---|---|
| Общая страница `/services` | Три верхних изображения заменены на визуальные сцены без текстовых карточек: продуктовый поток, запуск по уровням зрелости, нишевая карта заявок. |
| Главная | Четыре изображения `/images/home/*.png` пересобраны как визуальные сцены без заголовков и списков внутри картинки. |
| Страницы услуг `/services/*` | Все изображения `/og/services/*.png`, которые показываются в `ServiceImageBand`, пересобраны без SVG-текста и без старой карточной логики. |
| SEO-лендинги | Убрана автоматическая подмена `.png` на старые `.webp`; удалены `web-analytics.webp`, `website-development.webp`, `yandex-direct.webp`. |
| Блог | Обложки `/og/posts/*.png` пересобраны без заголовков внутри изображения. Текст статьи остается в HTML рядом с обложкой. |
| Бартер СТО | Пять квадратных изображений и hero-фон пересобраны как визуальные сцены без списков и подписей внутри картинки. |
| Старый контур генерации | Удалены `scripts/generate-image.mjs`, `scripts/build-image-batches.mjs` и все `scripts/image-batch-*.json`, чтобы не возвращаться к старому batch-процессу для абстрактных AI-картинок. |

## Контрольные правила

- Нельзя делать изображение как слайд с заголовком и списком.
- Нельзя добавлять псевдологотипы или похожие на бренд знаки.
- Нельзя использовать мутные интерфейсы с нечитаемыми буквами.
- Нельзя ставить текст в картинку, если этот текст уже есть рядом на странице.
- Можно использовать реальные логотипы Telegram, VK, Avito, Яндекс.Директ и MAX в визуальном контексте канала.
- Для SEO-гео смысл показывается через маршрут, карту, экран, заявку, CRM и график, а не через надписи внутри картинки.
