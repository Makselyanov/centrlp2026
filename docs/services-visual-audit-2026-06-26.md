# Аудит изображений CentrLP от 2026-06-26

Цель: убрать с публичных страниц сгенерированные декоративные картинки, псевдо-интерфейсы, текстовые слайды внутри изображений и несуществующие логотипы.

## Новое правило

- Визуал должен помогать понять соседний текст без дополнительного чтения внутри картинки.
- Внутри визуального блока не должно быть заголовков, списков, рекламных формулировок, псевдотекста и фейковых логотипов.
- Реальные логотипы платформ допустимы, если они относятся к каналу: Telegram, MAX, VK, Avito, Яндекс.Директ.
- Для SEO-страниц смысл передается через HTML-текст, структуру, schema/meta и контекстный визуальный блок, а не через надписи на картинке.

## Что изменено

| Зона | Решение |
|---|---|
| `/services` | Три верхних изображения заменены на HTML-визуалы без текста внутри картинки. |
| Главная | Четыре старых PNG-блока заменены на HTML-визуалы с иконками и реальными логотипами. |
| `/services/*` | `ServiceImageBand` больше не берет `/og/services/*`; используется контекстный визуальный блок по slug услуги. |
| SEO-лендинги | Старые PNG/SVG/WebP-превью отключены; hero-визуалы строятся из иконок этапов. |
| Блог | Карточки и страницы статей больше не берут `/og/posts/*`; используется общий контекстный визуал. |
| AI-страница | Псевдо-скрин CRM заменен на визуальную схему процесса без текста внутри картинки. |
| Бартер СТО | Hero и секционные PNG заменены на контекстные визуальные блоки; реальные VK-скриншоты оставлены. |
| OG/RSS | Персональные сгенерированные OG-картинки удалены; все превью ведут на реальный брендовый файл `/og/brand.jpg`. |
| Генераторы | Старые генераторы визуального мусора удалены из репозитория. |

## Контрольный стоп-лист

- Не добавлять обратно `public/images/home`, `public/images/services`, `public/images/barter/sto-*`, `public/og/posts` и `public/og/services`.
- Не подключать картинки с текстом вместо HTML-текста страницы.
- Не использовать мутные AI-интерфейсы с нечитаемыми буквами.
- Не рисовать похожие на бренд, но несуществующие логотипы.
- Новые визуалы для услуг делать через `ContextVisual` или реальные проверенные скриншоты.
