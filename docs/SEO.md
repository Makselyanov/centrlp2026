# SEO и Яндекс Вебмастер

## Что уже есть в проекте

На момент аудита в проекте уже присутствуют:

- `title`, `description`, canonical
- Open Graph и Twitter meta
- `robots.txt`
- `sitemap.xml`
- Yandex verification meta
- Yandex Metrika
- JSON-LD для `LocalBusiness`
- JSON-LD для `Article`, `BreadcrumbList`, `FAQPage`, `Service`
- блоговый контент в `content/posts`
- OG-изображения в `public/og`

То есть техническая база у сайта уже не нулевая.

## Что мешает сильному SEO прямо сейчас

### 1. Сайт остаётся SPA

Маршруты рендерятся через React Router, а метаданные многих страниц обновляются клиентским JavaScript уже после загрузки.

Это означает:

- не все роботы увидят route-specific meta одинаково хорошо
- social preview и поисковые сниппеты могут зависеть от JS-рендера
- для масштабного SEO лучше перейти к prerender/SSR хотя бы для ключевых страниц и статей

### 2. Деплой не стандартизирован

Пока источник правды размыт между:

- GitHub `origin`
- локальной машиной
- и серверным working tree

Для SEO это плохо, потому что невозможно надёжно вести:

- выпуск новых статей
- контроль sitemap/robots
- массовые редиректы
- технические релизы

### 3. Нужно отработать Яндекс Вебмастер по данным, а не по ощущениям

После подключения доступа нужно проверить:

- какие страницы в индексе
- какие страницы исключены
- есть ли дубли title/description
- какие запросы дают показы и клики
- есть ли проблемы с обходом, robots и sitemap
- как Яндекс определяет регион сайта

## Что стоит делать в первую очередь

### Уже можно делать в коде

- держать `robots.txt` и `sitemap.xml` в корректном состоянии
- наращивать SEO-блог по приоритетным кластерам
- усиливать внутреннюю перелинковку
- делать отдельные страницы под услуги и коммерческие интенты
- улучшать OG/meta/schema

### После доступа в Яндекс Вебмастер

1. Подтвердить главное зеркало и регион.
2. Проверить переобход для `sitemap.xml`.
3. Посмотреть индексирование новых статей.
4. Проверить исключённые URL и причины.
5. Разобрать CTR по страницам с показами.
6. Проверить 404/редиректы/каноникализацию.
7. Сверить поисковые запросы с текущими страницами услуг и статьями.

## Практический план

### Этап 1. Техническая база

- выровнять деплой
- держать корректные `robots.txt` и `sitemap.xml`
- убедиться, что все целевые страницы индексируемы

### Этап 2. Коммерческие страницы

- усилить страницы услуг под конкретные запросы
- проработать title/h1/description и интент
- добавить кейсы, FAQ, CTA, локальные сигналы по Тюмени

### Этап 3. Контент-машина

- публиковать статьи по кластерам
- перелинковывать их на услуги и проекты
- обновлять устаревающие материалы

### Этап 4. Работа по данным из Яндекс Вебмастера

- добирать запросы с показами, но слабым CTR
- устранять исключения из индекса
- усиливать страницы, которые уже начали ранжироваться

## Что полезно сделать следующим отдельным шагом

- перевести ключевые страницы и статьи на prerender/SSR
- настроить единый git-деплой без ручных правок на сервере
- подключить регулярный SEO-аудит после публикаций
