## Общие правила для всех проектов

### 1. Аккаунты
- 7 проектов → `i416597405@yandex.ru` (Я.Вебмастер) + `icq416597405@gmail.com` (GSC)
- РОСОМАХА → `rosomaha-rus999@yandex.ru` (отдельно)
- **НИКОГДА** не смешивать: чужой проект не должен быть в твоём Вебмастере

### 2. Что НИКОГДА не делаем (анти-чёрный список)
- Doorway-страницы «услуга в городе N» массовым методом
- AI-генерация без ручной редактуры (особенно YMYL: здоровье питомцев, право, налоги)
- Закупка ссылок на биржах (Sape, Miralinks, GoGetLinks) — для Яндекса это красный флаг
- Копипаст одной и той же статьи: сайт + Дзен + Telegraph одновременно
- Скрытый текст, белый шрифт на белом, накрутка поведенческих
- Использование `X-Robots-Tag: noindex` и индексация одновременно (каннибализация)
- Размещение закрытых SaaS (кабинеты) в sitemap

### 3. Правило канонизации по поддоменам
Жёсткое разделение:
- **Маркетинг** = открытые поддомены и корни доменов → индексируется
- **Кабинеты / app / admin** = либо поддомен `app.*`, либо путь `/app`, `/cabinet`, `/admin` → Disallow + X-Robots-Tag: noindex, nofollow
- **Тенант-субдомены** (`rosomaha.centrlp.ru`) = noindex, не в sitemap parent, не упоминаются в блогах как ссылка без `rel=nofollow noopener`

### 4. Schema.org обязательный минимум для всех
- `Organization` + `WebSite` на главной
- `BreadcrumbList` везде кроме главной
- `Article` в блоге
- `Service` / `Product` / `SoftwareApplication` на коммерческих страницах
- `FAQPage` где есть FAQ-блоки

### 5. IndexNow и переобход
- Настроить IndexNow ключ в `/public/{key}.txt` на каждом домене
- При публикации любой новой страницы → POST на `https://yandex.com/indexnow` и `https://api.indexnow.org/indexnow`
- Для Я.Вебмастера — скрипт переобхода (уже есть на centrlp и rosomaha → копировать в остальные)

### 6. Аналитика обязательный минимум
- Яндекс.Метрика с веб-визором на всех проектах
- GA4 — только где реклама Google (centrlp, svrq, aamx). Для остальных — опционально
- Цели: форма, телефон, Telegram, WhatsApp, скролл 75%, время 2 мин
- Офлайн-конверсии (YooKassa, заключённые договоры) через Measurement Protocol
